# Projet-Java



Pour l'utilisation de la release, il faut dans Eclipse :
  -Créer un nouveau projet Java
  -Cliquer droit sur ce projet 
  -Aller dans Build Path puis dans Add External Archives
  -Sélectionner le fichier téléchargé dans la release 
  -Lancer le tout en cliquant droit sur le projet et cliquant sur Run As puis Java Application
